# ClipTiny

一个极简、原生、无第三方依赖的 macOS 剪贴板管理器，支持文本和图片。

> 仓库名是 SimpleClip，应用本身叫 ClipTiny。

## 功能

- `⌘⇧V`：打开或关闭剪贴板历史
- `⌘F`：聚焦搜索框
- `↑ / ↓`：选择记录，右侧同步预览完整内容
- 每条记录都带时间戳，列表精确到分钟，预览区精确到秒
- `Enter`：写回剪贴板，关闭窗口，并优先粘贴到光标所在的输入框
- `Esc`：关闭
- 支持复制、预览和粘贴图片（截图、浏览器图片等）
- 最多保留 100 条，数据仅保存在本机
- 历史和图片都使用 AES-GCM 加密，密钥仅保存在 macOS 钥匙串
- 记住窗口上次关闭或隐藏时的位置和大小
- 忽略 macOS 标记为临时、保密或自动生成的剪贴板内容

`Enter` 之后的行为：内容先写回系统剪贴板，窗口立即关闭并回到之前的应用；
如果那里有可输入的文本光标，就自动粘贴过去；如果没有（例如停在 Finder 或
桌面），内容会留在系统剪贴板，之后手动按 `⌘V` 即可粘贴。

## 构建

```sh
chmod +x scripts/build-app.sh
./scripts/build-app.sh
```

脚本使用系统自带的 Swift 编译器，不需要安装 Xcode 或第三方依赖，并会生成
同时支持 Apple 芯片与 Intel Mac 的通用应用。图标已经生成好放在
`Resources/AppIcon.icns`，只有改图形时才需要跑 `./scripts/make-icon.sh`。
完成后双击 `outputs/ClipTiny.app`。首次用 Enter 自动粘贴时，macOS 可能请求一次
“辅助功能”权限；允许后即可自动粘贴。若拒绝，所选记录仍会复制到系统剪贴板，
可手动按 `⌘V` 粘贴，应用不会重复弹出权限窗口。也可以在“系统设置 → 隐私与安全性
→ 辅助功能”中手动允许 ClipTiny。

如需开机启动，可在“系统设置 → 通用 → 登录项”中添加 ClipTiny。

当前是 ad-hoc 本地签名，适合自己构建自己用。从别处下载的构建产物首次打开时
Gatekeeper 可能会拦，对外正式分发需要 Apple Developer ID 签名并做公证。

## 隐私

- 无网络请求，无遥测，无第三方依赖。
- 历史存在 `~/Library/Application Support/ClipTiny/`，用 AES-GCM 加密，
  密钥由 macOS 钥匙串保管，磁盘上没有明文。
- 图片单独加密存在同目录的 `images/` 下。
- 自动跳过被标记为 `TransientType`、`ConcealedType`、`AutoGeneratedType` 的
  剪贴板内容（部分密码管理器会这样标记）。

内部结构、数据格式和回归测试清单见 [MAINTENANCE.md](MAINTENANCE.md)。
